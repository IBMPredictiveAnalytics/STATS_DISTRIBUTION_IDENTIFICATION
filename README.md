# STATS_DISTRIBUTION_IDENTIFICATION


---
Requirements
----
- IBM SPSS Statistics 24 or later
- R 4.0 or later 
- R packages: nortest, jsonlite (plotly optional: an offline copy of the chart library for the HTML report)


---
Installation instructions
----
1. Open IBM SPSS Statistics
2. Navigate to Extensions -> Extension Hub 
3. Search for **STATS DISTRIBUTION IDENTIFICATION** and click Ok. Your extension will be available.

Alternatively, install manually:
1. Download `STATS_DISTRIBUTION_IDENTIFICATION.spe`
2. Navigate to Utilities -> Extension Bundles -> Install Local Extension Bundle
3. Select the downloaded `.spe` file and click Open

The procedure is in Analyze -> Quality Control -> Distribution Identification, next to Process Capability Analysis (STATS PROCESS CAPABILITY), which uses the recommended distribution.
